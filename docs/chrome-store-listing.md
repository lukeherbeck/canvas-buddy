# Chrome Web Store Listing Draft

## Category

Education

## Single Purpose

CanvasBuddy turns a student's Canvas to-do list into a daily quest panel with a growing buddy, projected XP, streak progress, and Canvas-verified completion rewards.

## Short Description

Turn Canvas assignments into daily quests with a buddy that levels up as work gets done.

## Full Description

CanvasBuddy adds a lightweight companion panel to Canvas. It reads the assignments and upcoming work the student is already signed in to view, ranks the top daily quests, previews XP rewards, and keeps buddy progress local in Chrome.

Completion rewards are Canvas-verified. CanvasBuddy does not add a manual claim button; XP is awarded only when a previously tracked Canvas to-do disappears from the live Canvas to-do list.

Trusted beta features:

- Daily quest panel with the top Canvas assignments
- Urgency labels for overdue and soon work
- Projected XP rewards before completion
- Buddy level, streak, and progress stats
- Local-only storage for settings and buddy progress
- Narrow host access for known Canvas domains

CanvasBuddy is not affiliated with Instructure, Canvas, Texas A&M University, or any school.

## Privacy Summary

CanvasBuddy processes Canvas assignment data locally in the browser and stores extension settings and buddy progress in Chrome extension storage. The trusted beta does not use a backend, analytics, advertising, remote code, or data sale.
