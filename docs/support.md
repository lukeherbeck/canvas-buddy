# CanvasBuddy Support

CanvasBuddy is currently a Trusted beta for Chrome.

## What CanvasBuddy Does

CanvasBuddy adds a small companion panel to known Canvas hosts. The panel shows the user's top Canvas assignments, projected XP, streak status, and buddy progress.

## Before Reporting A Bug

1. Confirm the extension is enabled in the popup.
2. Open a supported Canvas URL such as `https://canvas.tamu.edu/` or an `https://*.instructure.com/` school domain.
3. Refresh the Canvas tab once after installing or updating the extension.
4. Use the panel's Recheck or Refresh action.

## Known Beta Limits

CanvasBuddy only supports known Canvas hosts in this beta. It does not support every custom school Canvas domain yet. CanvasBuddy also does not award manual XP; completion XP is awarded only when a previously tracked Canvas to-do disappears from the live Canvas to-do list.

## Privacy

CanvasBuddy is local-only in the trusted beta. It stores settings and buddy progress in Chrome extension storage and does not send Canvas data to a CanvasBuddy server.

## Contact

Use the Chrome Web Store support contact for beta feedback, bugs, and school-domain requests.
