# CanvasBuddy Privacy Policy

Effective date: beta launch

CanvasBuddy is a browser extension that helps students turn Canvas assignments into a small daily quest loop. CanvasBuddy is designed as a local-only trusted beta.

## Data We Process

CanvasBuddy reads assignment and calendar data from Canvas pages and Canvas API responses that the user is already signed in to view. This may include assignment names, due dates, links, points possible, and completion state.

Canvas data is processed locally in the browser. CanvasBuddy stores extension settings, buddy progress, quest tracking, streaks, and lightweight diagnostics in Chrome extension storage so the extension can remember the user's preferences and rewards.

## Data We Do Not Collect

CanvasBuddy does not sell user data. CanvasBuddy does not transfer user data to third parties. CanvasBuddy does not use user data for advertising, credit decisions, or eligibility decisions. CanvasBuddy does not collect analytics during the trusted beta.

CanvasBuddy does not use remote code. The trusted beta runs the code packaged with the extension, plus Canvas pages and APIs that the user already has permission to access.

## Network Activity

CanvasBuddy calls Canvas URLs from the current Canvas site to load the user's to-do and upcoming work. CanvasBuddy does not send Canvas data to a CanvasBuddy server because no CanvasBuddy server is used in the trusted beta.

## User Controls

Users can disable CanvasBuddy from the extension popup. Users can also remove extension data by uninstalling the extension or clearing extension storage in Chrome.

## Affiliation

CanvasBuddy is not affiliated with Instructure, Canvas, Texas A&M University, or any school.

## Contact

For support or privacy questions, use the support contact listed on the Chrome Web Store beta listing.
